# API documentation

This folder holds the published API contracts for SAHANA.

Planned contents, created during Milestone 0 and later milestones:

- OpenAPI specification for the common REST API used by the web and mobile clients.
- Authentication, error, pagination, and idempotency conventions that supplement `docs/ai/DEVELOPMENT_GUIDE.md`.
- Per-module contract notes when a contract needs explanation beyond the OpenAPI file.

Do not place secrets, environment addresses, or sample credentials in this folder.
