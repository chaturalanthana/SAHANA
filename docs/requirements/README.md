# Requirements

Source of truth for what SAHANA must do.

- `TRACEABILITY_MATRIX.md` maps each approved SRS clause and each MVP module to a milestone, a status, and any open decision that blocks implementation.
- The approved baseline is *SAHANA Initial SRS v1.0* (31 October 2026). The October 2026 solution proposal for the CBL Employee Welfare Society is context, not a substitute for the SRS.
- When a requirement and an implementation conflict, stop the affected work and record the conflict in `docs/decisions/DECISIONS.md`.
