# Testing documentation

This folder holds test strategy, representative workloads, and executed test evidence.

Planned contents:

- Unit, API, and web end-to-end scope (Vitest and Playwright).
- The 100,000-member representative dataset definition required by SRS 033.
- Financial reconciliation cases and localization checks.
- Records of tests actually run, including date, command, and result. A document must not claim a pass that was not executed.
