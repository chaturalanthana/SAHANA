# Security documentation

This folder holds SAHANA security controls that are reviewed before release.

Planned contents:

- Threat notes for society isolation, authentication, document access, and financial posting.
- Secrets-handling rules that expand SRS 030.
- Backup, recovery, and incident-procedure records once hosting decisions (OD 07) are approved.
- Evidence of security testing performed in Milestone 6. Do not record a control as verified until the test has been executed.

Do not store keys, connection strings, or production configuration here.
