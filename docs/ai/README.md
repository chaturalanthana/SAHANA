# AI governance

Every coding agent working in this repository reads these documents before changing code or schema:

1. `AI_CONSTITUTION.md` — permanent engineering principles.
2. `NON_NEGOTIABLE_RULES.md` — release-blocking rules.
3. `DEVELOPMENT_GUIDE.md` — how to build a change.
4. `UI_UX_GUIDE.md` — how screens must behave.
5. `IMPLEMENTATION_PLAN.md` — milestone order and gates.

The root `AGENTS.md` points here. Do not bypass these documents because a task looks small.
